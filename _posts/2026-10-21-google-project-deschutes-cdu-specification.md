Project Deschutes 是 Google 提交给 Open Compute Project（OCP）的第五代冷却液分配单元规格，面向高功率、高密度 IT 集群，包括 AI/ML 加速器机群。其额定换热能力为 2 MW，IT 侧和设施侧的设计流量均为 500 GPM，属于数据中心设施级 CDU，而不是单机柜内的小型供液装置。

本文参数依据 OCP 于 2026 年 2 月 26 日生效的 [Project Deschutes v1.0 规格书](https://www.opencompute.org/documents/ocp-specification-deschutes-v1-0-pdf)整理。规格书给出的是开放设计要求及首选器件，不等同于某一台商品化设备的最终出厂数据。

## 1. 核心参数

| 项目 | 规格书标称值 | 常用公制换算或说明 |
|---|---:|---|
| 额定热负荷 | 2000 kW | 2 MW |
| IT 侧流量 | 500 GPM | 约 113.6 m³/h |
| 设施侧流量 | 500 GPM | 按 0.25 GPM/kW 配置 |
| IT 侧可用压差 | 80～90 psi | 约 552～621 kPa |
| 设施侧压降 | 15～30 psi | 约 103～207 kPa |
| 工作压力 | 0～130 psig | 上限约 896 kPa（表压） |
| 工作液温 | 18～55 ℃ | 一、二次侧液体工作范围 |
| 换热器逼近温差 | 3 ℃ | 2 MW 设计目标 |
| 换热器形式 | 液—液 | 推荐双流程板式换热器 |
| 冷却液 | DI 水基冷却液、PG25 | PG25 为 25% 丙二醇溶液 |
| 设备功耗 | 74 kW | 对应两台 37 kW 泵的额定功率合计 |
| 泵供电电压 | 380～416 Vac | 三相，50/60 Hz |
| 外形尺寸（宽×高×深） | 65.25×91.44×42.29 in | 约 1.657×2.323×1.074 m |
| 最大干重 | 5300～5310 lb | 约 2.40～2.41 t |
| 最大湿重 | 6900 lb | 约 3.13 t |
| 含包装最大高度 | 100 in | 约 2.54 m |

按外形包络计算，设备占地约 1.78 m²。湿重平均分布时约为 1.76 t/m²；实际项目仍应按底脚位置、抗震支架和局部集中载荷复核楼板，不能直接使用平均值代替结构计算。

![Project Deschutes CDU 三维结构视图二](/assets/images/project-deschutes-cdu/cdu-view-2.png)

*图 2：另一侧结构视图，可见三组并联板式换热器、两套泵组及大口径主管路。*

整机采用一次侧与二次侧隔离的液—液换热结构：

- 一次侧连接数据中心设施水系统，将热量带往冷却塔、干冷器或其他热排散设备；
- 二次侧连接 IT 设备冷却回路，为服务器冷板供液；
- 三台双流程板式换热器并联，以降低流动阻力并提高换热能力；
- 两台无轴封泵分别配置变频器，按 N+1 方式运行；
- 机架带脚轮和固定支架，泵、过滤器及主要维护件可从正面或侧面抽出检修。

规格书原型图还标出了 13 gal 膨胀罐、2 gal 辅助膨胀罐以及 5 gal 膨胀/储液罐。具体量产实现允许调整，但应保留流通式膨胀容积、补液排气及可维护性要求。

## 3. 换热能力

Project Deschutes 采用三台双流程板式换热器并联。首选器件为 Alfa Laval CB210-276AH，目标是在一次侧和二次侧均为 500 GPM、总热负荷 2 MW 时，将逼近温差控制在 3 ℃以内。

规格书给出的换热性能点如下：

| 总流量 | 总热负荷 | 双流程换热器逼近温差 |
|---:|---:|---:|
| 162 GPM | 640 kW | 1.6 ℃ |
| 234 GPM | 922 kW | 1.8 ℃ |
| 324 GPM | 1280 kW | 1.9 ℃ |
| 389 GPM | 1536 kW | 2.1 ℃ |
| 467 GPM | 1843 kW | 2.2 ℃ |
| 545 GPM | 2150 kW | 2.3 ℃ |
| 623 GPM | 2458 kW | 2.4 ℃ |

这些点说明，3 ℃并不是正常工况下必须达到的固定温差，而是设计上限。随着流量提高，换热器两侧的逼近温差可以进一步降低，但泵功耗和系统压降也会增加。

## 4. 泵组与水力设计

规格书首选泵型为 SPECK TOEMA065200，单泵设计点为 500 GPM、112 psi，额定功率 37 kW。两台泵均配置独立 ABB ACH580-31-065A-4 变频器，并采用无轴封结构。

| 泵组项目 | 参数 |
|---|---|
| 数量 | 2 台，N+1 运行 |
| 单泵流量 | 500 GPM，约 113.6 m³/h |
| 单泵扬压 | 112 psi，约 772 kPa |
| 单泵功率 | 37 kW |
| 调速方式 | 每台泵独立 VFD |
| 默认控制目标 | 保持 IT 供、回水之间的固定压差 |
| 其他控制模式 | 定流量、定供水温度、定回水温度、定转速 |

单台泵即可覆盖设计流量，另一台承担冗余。泵进出口设置隔离阀和排水口，允许停运单泵后滑出维护，而不必将整个二次侧管路全部拆开。

## 5. 过滤、排气和材料

二次侧主过滤精度为 25～44 μm，过滤器要求正面可维护；旁通支路另设 0.2 μm 微过滤器，支路流量约 3 GPM。一次侧入口还设置 500 μm 粗滤器。这样的分级方式兼顾了主管路压降与细颗粒控制，0.2 μm 滤芯不承担全部主流量。

系统同时配置空气分离器、流通式膨胀罐、补液口和排液口。三条区域式漏液检测绳接入 PLC，可判断不同位置的泄漏报警。

与冷却液接触的主要材料限定为不锈钢、铜和 EPDM。二次侧不允许使用镀镍黄铜；一次侧原则上也应避免，确需使用时须由客户确认。该限制与长期水化学兼容性、镀层失效和颗粒污染风险有关。

支持的冷却液包括：

- ChemTreat CL2002：95% 去离子水与 5% 添加剂；
- Garratt-Callahan FM5666-LT：98% 去离子水与 2% 添加剂；
- Veolia Suez SV5520：97% 去离子水与 3% 添加剂；
- PG25：25% 丙二醇溶液。

## 6. 控制与监测

PLC 同时支持 IPv4 和 IPv6，现场界面采用 HMI，并通过 Modbus/TCP 对外提供数据。IPv6 功能覆盖 DHCPv6、SLAAC 和 NDP。

正常运行时，泵组以 IT 侧供回水压差为主要反馈量；一次侧调节阀默认根据逼近温差调节设施水流量。控制器还允许选择固定流量、固定供水温度、固定回水温度、固定泵速或固定阀门开度等模式。多台 CDU 可以各自独立运行，也可以并联接入同一公共总管。

关键遥测量包括：

- IT 侧和设施侧供回水温度、绝对压力；
- CDU 总流量，流量计精度为读数的 ±0.5%；
- 泵转速、泵功率和变频器状态；
- 一次侧调节阀开度；
- pH 值和电导率；
- 漏液、泵电机过温及其他故障报警。

## 7. 电气参数

设备额定输入为 380～416 Vac 三相电，允许在标称电压的 90%～110% 范围内运行，即约 342～458 Vac；频率范围为 47～63 Hz。每台 50 hp 变频器对应约 37.3 kW，功率因数为 0.98～1.00。

在 342 Vac、满载条件下，单台变频器相电流约 64 A。规格书建议初始采用 80 A 熔断器，若现场出现误动作，可提高至最大 100 A；隔离开关和熔断器座按 100 A、100 kA SCCR 配置。PDU 要求双路 416 Vac 供电，最低满足 1N 输入冗余，推荐做到 2N。

74 kW 是两台泵额定功率的合计值，相当于 2 MW 额定换热量的 3.7%。这只是设备额定功率与额定热负荷之比，不是实际运行能效：变频泵在部分负载下的功耗取决于系统阻力、目标压差和实际转速。

## 8. 环境与可靠性边界

| 项目 | 要求 |
|---|---|
| 运行环境温度 | 海拔 1700 ft 以下为 15～40 ℃；7600 ft 为 15～32 ℃ |
| 相对湿度 | 8%～80%，无凝露 |
| 目标可用率 | 99.999% |
| 接插件防护 | IP66 |
| 泵、电机及驱动防护 | IP55 |
| 安全认证 | UL/IEC/EN 62368-1、UL/cUL、CB、CE |
| 系统保压试验 | 150 psi、24 h |
| 压力循环 | 0～150 psi，1000 次 |
| 系统爆破边界 | 250 psi 以下不得破裂或泄漏 |

规格书还覆盖运输振动、机械冲击、地震固定、水锤、软管弯折、阀门循环、泵与变频器热插拔等验证项目。其设计重点并不只是把 2 MW 热量换出去，而是让过滤、泵、驱动和传感器在不中断整机供液的条件下可隔离、可维护、可监测。

## 9. 参数落地时需要注意的几点

第一，500 GPM 是一次侧和二次侧的设计流量，不代表任何工况都必须恒定在该流量。变频泵和一次侧调节阀会随负载调整。

第二，80～90 psi 是 CDU 可提供给 IT 回路的压差能力，112 psi 是首选泵的设计点，两者之间还要扣除 CDU 内部管路、过滤器、阀件和换热器的压降。

第三，3 ℃是换热器一次侧与二次侧之间的逼近温差目标，不是 IT 供回水温差。服务器冷板回路的供回水温差需要根据实际热负荷、流量和冷却液物性另行计算。

第四，2 MW 级设备的湿重超过 3 t，运输通道、门洞、吊装、地面承载、底脚集中载荷和抗震固定必须在土建设计阶段同步确认。仅看设备外形尺寸通常不够。

Project Deschutes 的价值在于把大容量 CDU 的热工、水力、电气、控制、维护和可靠性要求放进了一套公开规格。对自研 CDU 而言，三台板换并联、双泵 N+1、分级过滤、双路供电和完整遥测，可以直接作为总体方案评审时的基准清单；实际选型仍需结合数据中心一次侧水温、服务器允许水质、管网阻力和冗余等级重新校核。
